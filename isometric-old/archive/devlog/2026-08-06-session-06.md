### Audio: the 5-layer softsynth

- Five voices, all pure functions of a sample counter (deterministic by construction): Base (C2
  saw drone), Strings (saw arpeggio), Pad (sine), Bells (sine plucks with decay/retrigger), Voice
  of Souls (sine + 6 Hz tremolo). Static pattern tables over a 16-step × 0.5 s grid (8 s loop),
  C-minor Cm–Ab–Eb–Bb progression. `decay` semantics = 1/tail-seconds.
- Fragment restores activate Strings→Pad→Bells at frag counts 1/2/3; souls activate the Voice.
  E-key routes: portal→`SFX_PORTAL` (noise burst), restore→`SFX_CHIME` + layer/voice fire,
  fragment→`SFX_SHARD`.
- Real-time discipline preserved: game thread only bumps atomics (`layer_fire`, `voice_fire`,
  `reset_req`, per-SFX `fire`); callback latches. R/F9 zero the synth via `reset_req`, no
  main-thread race.
- `--audio-test --layers --sfx`: worst case 0.325 ms vs 21.333 ms deadline (1.5%), peak 0.9151,
  NaN 0, clipped 0, partial writes 0. Offline determinism: 96,000 samples from two fresh states
  bit-identical.

### HUD, on the Phase 03 font

- The font was un-gated and **extended with lowercase a–z and `/`** (0x20–0x5F → 0x20–0x7A, 91
  glyphs). The uppercase-only table was the whole reason the first HUD pass showed nothing but
  digits: `draw_glyph` silently skipped every lowercase char. Root-caused by pixel probes in the
  toast region, fixed in the table, and now pinned by `--font-test` (3736 px expected == rendered;
  stride negative control still caught) and `--hud-test`.
- Counters top-left; restore toasts bottom-centre (180 frames, fade over the last 30); win banner
  centre (once); seed bottom-right; minimap top-right (2 px/tile on a cached surface, redrawn on
  dirty or every 15 frames). Legend: You / Restored / Unrestored / Soul / Fragment.
- `--hud-test` (new): pixel-presence probes — counters, minimap coverage (44,928/44,928 px),
  exact-white player marker on its minimap tile, seed line, toast shown → expired (with a
  world-refill simulating the next frame, matching how the game actually erases a toast), win
  banner, whole-land line. All PASS. One test-side fix: the "expired" check needed a refill
  between frames — the toast stops drawing at expiry but pixels persist until the next render.

## Bug found the same day: shards could not be collected

The E-key branch restructure this session introduced a dead branch: the chain was
`if (!grid && try_portal) … else if (!grid) { try_restore } … else if (!grid && try_collect_shard)`,
and the middle `else if (!grid)` matched every non-grid press, so the shard branch was
unreachable. Nothing caught it because every shard test bypassed the key path — the autopilot
collects shards by calling `try_collect_shard` directly, and `--shard-test` drove
`entity_in_reach`/`try_restore`, never E.

Fixed by extracting the whole interaction into one `try_interact(Game *, Audio *)` (portal →
restore → shard pickup; returns 1/2/3/0) that the E/Space handler now calls, and `--shard-test`
now drives **that exact function**: a shard is dropped at the player's feet at the Well and must
be collected through the real path (`shard pickup: PASS`). `--shard-test` is now the load-bearing
regression for the key path. Full suite re-run green, release size unchanged at 786,432.
