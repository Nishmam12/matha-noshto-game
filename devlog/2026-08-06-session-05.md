### What landed, and where

1. **Tree sway.** `tree_sway()` at the prop dispatch (`draw_prop`), one formula shared by the
   baked-sprite path and the procedural `draw_tree` fallback, so a forest of mixed assets sways
   in phase. Whole-tree offset from hash bits 27-31 (per-instance) × 1-2 px; `draw_tree` adds a
   per-lobe ripple (`i * 0.55` phase offset per lobe) so the crown breathes rather than sliding.
   Only trees — a bush rocking reads wrong.
2. **Water shimmer.** `water_ripple()` in `tile_colour` for river and ocean: ±5 px brightness
   ripple on the ramp colour, kept under one ramp step so no tile ever flips depth band. Silent in
   the `--overlay` region view; dream-side void excluded (the starfield is its motion).
3. **Waterfall fall-lines.** Phase 06's waterfalls are height-terraced river tiles — the drop is
   the side face `iso_tile` paints. `waterfall_dash()` replicates iso_tile's column math so the
   streak lands ON the face, and scrolls a pale 1-px dash down it (`fmod`-free wrap, so no float
   library surface). River tile with an exposed down-face only.
4. **Chimney smoke.** `draw_smoke()`: 1 puff while the restoration-rebuild is in its 0.7-1.0
   window (procedural chimney), 2 puffs over the baked sprite at full restoration — the smoke
   rides the same 1.0 threshold as `bld_phase`.
5. **Fireflies.** `mote_gate()` + inline position: grass-only, one tile in eight, never on a
   path/footprint, only in regions ≥ 70% restored, with presence and brightness ramping to full
   at 1.0. The gate is one shared function so `--motion-test` tests the code that renders.
6. **Found Souls idle-bob.** `soul_bob()`: ±2 px about the entity's tile-hash phase. Fragments
   stay static deliberately (markers, and a bobbing pick-up reads like it is running). The two
   soul prompts ride the same `sy`, so the padlock/interact cue bobs with its soul.

Every effect is a pure `(tile_hash, g->clock)` render-time function; zero new simulation state,
zero touched RNG streams.
