### Session 17b — levitating houses on packed-earth plinths (reported by the user, fixed)

**Symptom:** every building stood on a tall featureless tan box. Reported from live play on seed 4.
**Not caused by the character switch** — this is a Session 15 regression, visible at HEAD.

**Root cause: three pieces of code disagreeing about whether a baked building's footprint is
flattened.**

| Where | What it does | Believes |
|---|---|---|
| `world_heights` (~3253) | always extrudes `WALL_BASE + levels*STOREY_H` | footprint is a WALL |
| `tile_colour` (~6034) | paints packed earth `0x8f7d5e` | footprint is flat GROUND |
| `draw_building` (~5635) | drew the sprite at `cy - wall` | footprint is a WALL |

So every footprint became a tall box painted with a *ground* colour, with the house perched on top.
`building_sprite_id` is a pure function of variant/size and `art_bld_small`/`art_bld_large` hold no
`ART_NONE`, so **every** building takes that path — there is no building in the world without a
plinth.

The pre-Session-15 code carried a guard with a comment describing this exact failure: *"UNLESS the
building is drawn as a baked sprite... the ground under it must stay FLAT. Leaving the extrusion in
place stood a 96 px house on top of a 42 px block, which read as a cottage on a plinth."* Session 15
deleted the guard while fixing a genuine second bug (at phase 0 nothing was drawn at all, because
the sprite was gated on `phase >= 3` — villages were invisible from a cold start).

**Fix — keep Session 15's visibility win, restore the flattening:**
- `world_heights`: flatten again when `building_sprite_id(bb) != ART_NONE`.
- `draw_building`: draw the sprite at `cy`, not `cy - wall`; smoke likewise.
- **Kept** Session 15's removal of the `phase >= 3` gate, so villages still render from a cold
  start. Nothing regresses relative to current behaviour; the plinth simply goes.

**Proven by a same-seed before/after** (`--frames 200 --seed 3 --overlay --shot`, Session-15
behaviour temporarily restored to capture the "before"): every house and windmill on a tan block
before, flat on the ground after.

**Verified:** default gate **23/23**, `--play-test --seeds 50` **50/50**. Release **1,085,440, +0
bytes** — render-only. Zero warnings.

**NOT verified / left open:** the ruin→whole restoration rebuild is **not visible for baked
buildings** — the sprite draws at every phase, so a village looks finished before it is restored.
