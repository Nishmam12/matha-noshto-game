# Phase 12 — Dream Realm Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: use `superpowers:subagent-driven-development`
> (recommended) or `superpowers:executing-plans` to implement this task-by-task. Steps use
> checkbox syntax for tracking.
>
> **NOTE ON LOCATION.** The writing-plans skill defaults to `docs/superpowers/plans/`. This project
> keeps every design artefact in the Obsidian vault under `design/phases/`, wikilinked, and
> [[Handover]] §10 requires that every new note link to an existing one or the graph breaks. So the
> plan lives beside its spec, [[Phase 12 - Dream Realm]].

**Goal:** A portal in the `TERRAIN_DARK` region leading to a second, Lumiara-styled biome that
holds 4 fragments, 2 Found Souls, 8 dream shards and a Dream Well.

**Architecture:** One grid, not two worlds. `WORLD_H` grows 60 → 104; the overworld keeps rows
0–59, an unwalkable void band takes 60–63, and the dream archipelago takes 64–103. A single
`tile_neighbours()` supplies graph adjacency — the four orthogonal tiles plus the portal's paired
tile — and every traversal in the project routes through it, so walk-reachable == graph-reachable
stays true by construction. Collision is untouched: travel is an `E` interact, not a movement.

**Tech Stack:** C99, single translation unit `src/main.c` (~6,900 lines). Static SDL2 at
`G:\tools\SDL2-min`. Build with `.\build.ps1` / `.\build.ps1 -SelfTest`. Art bakes through
`tools\bake.ps1` into the committed `src\art_data.h`.

## Global Constraints

Copied from [[Handover]] and [[Phase 12 - Dream Realm]]. **Every task's requirements implicitly
include this section.**

- Final `.exe` ≤ **1,440,000 bytes** ship target. Report the exact byte size and delta after
  **every** build. `build.ps1` exits non-zero over budget.
- **Collision reads `solid` and `regions[].terrain` and nothing else.** If any task makes collision
  read `height`, `bld_at`, `surf`, `bridge`, `sea_dist` or a portal field, stop and flag it.
- **Every new checker needs a negative control.** A checker that has never rejected anything proves
  nothing.
- **Zero warnings** under `-Wall -Wextra`. Warnings are defects.
- **Zero external files ship.** Art enters only through `tools\bake.ps1` → `src\art_data.h`.
- Any change to generation or placement means re-**running** the suite, not re-arguing it —
  minimum `--reach-test --seeds 50`, `--gating-test --seeds 30`, `--play-test --seeds 50`.
- `Game` and `Scratch` are **stack locals, never statics** (the `.data`/`.bss` COMDAT trap).
- **No `Co-Authored-By` trailers in commits.** Asked for explicitly; one had to be stripped and
  force-pushed once.
- `src\art_data.h` is **generated**. Never hand-edit; re-run the bake and commit the result.
- Wrap every new hand-authored pixel dimension in `PX()` or it opts out of the `TILE` scale system.
- Work on branch `feat/phase-12-dream-realm`.

- [ ] **Step 1: Write the failing test.** Add above `sprite_selftest`:

```c
/* The dream realm is a second landmass in the SAME grid (see the spec's approach A). Three
 * claims, and the third is the one that matters: before the portal exists the two sectors must be
 * genuinely unreachable from each other, or the portal is decoration rather than the only way
 * across, and --portal-test in Task 4 would pass for the wrong reason. */
static int sector_selftest(Uint64 seed, int nseeds)
{
    int fails = 0, s;

    for (s = 0; s < nseeds; s++) {
        Game *g = (Game *)SDL_malloc(sizeof(Game));
        Scratch *sc = (Scratch *)SDL_malloc(sizeof(Scratch));
        Rngs rngs;
        int over = 0, dream = 0, band_open = 0, x, y, i;

        if (!g || !sc) { printf("FAIL  out of memory\n"); SDL_free(g); SDL_free(sc); return 1; }
        rngs_init(&rngs, seed + (Uint64)s);
        SDL_zerop(g);
        world_gen(&g->w, &rngs.terrain);

        for (y = 0; y < WORLD_H; y++)
            for (x = 0; x < WORLD_W; x++) {
                if (g->w.solid[y][x]) continue;
                if (dream_sector(y)) dream++; else over++;
                if (y >= OVERWORLD_H && y < DREAM_Y0) band_open++;
            }

        if (over < 400) { printf("FAIL  seed %d: overworld has %d walkable tiles\n", s, over); fails++; }
        if (dream < 200) { printf("FAIL  seed %d: dream sector has %d walkable tiles\n", s, dream); fails++; }
        if (band_open)   { printf("FAIL  seed %d: %d walkable tiles in the void band\n", s, band_open); fails++; }

        /* Separation. Flood from the first walkable overworld tile and require that it reaches
         * nothing in the dream sector. */
        for (i = 0; i < WORLD_W * WORLD_H; i++) sc->seen[i] = 0;
        {
            int fx = -1, fy = -1, first, sx, sy;
            for (y = 1; y < OVERWORLD_H && fx < 0; y++)
                for (x = 1; x < WORLD_W - 1; x++)
                    if (!g->w.solid[y][x]) { fx = x; fy = y; break; }
            if (fx < 0) { printf("FAIL  seed %d: no overworld tile to flood from\n", s); fails++; }
            else {
                int leaked = 0;
                flood_open(&g->w, sc->seen, sc->stack, fx, fy, &first, &sx, &sy);
                for (y = DREAM_Y0; y < WORLD_H; y++)
                    for (x = 0; x < WORLD_W; x++)
                        if (sc->seen[y * WORLD_W + x]) leaked++;
                if (leaked) {
                    printf("FAIL  seed %d: overworld flood leaked into %d dream tiles\n", s, leaked);
                    fails++;
                }
            }
        }
        SDL_free(g); SDL_free(sc);
    }

    /* Negative control: a sector predicate that never separates anything. If the separation
     * assertion above cannot reject "everything is one sector", it is not testing separation. */
    {
        int bad = 0, y;
        for (y = 0; y < WORLD_H; y++)
            if (dream_sector_always_false(y) != dream_sector(y)) bad++;
        printf("negative control (sector-blind predicate): %s  [disagrees on %d of %d rows]\n",
               bad > 0 ? "PASS" : "FAIL", bad, WORLD_H);
        if (!bad) fails++;
    }

    printf("%s (%d checks failed)\n", fails ? "FAIL" : "PASS", fails);
    return fails ? 1 : 0;
}
```

- [ ] **Step 4: Split `world_gen` into two sector passes.** Extract the body of the existing
double loop (`src/main.c` ~794–824) into a helper, normalising `fy` **within the sector** so each

```c
/* One landmass, over rows [y0, y1). fy is normalised INSIDE the range, so the radial term makes
 * each sector its own island rather than one lobe of a grid-sized one. */
static void gen_sector(World *w, Rng *rng, int y0, int y1, float sea, float rough)
{
    float lat0[LAND_LAT_W * LAND_LAT_H];
    float lat1[LAND_LAT2_W * LAND_LAT2_H];
    float rock[LAND_ROCK_W * LAND_ROCK_H];
    int x, y, span = y1 - y0;

    land_lattice(rng, lat0, LAND_LAT_W * LAND_LAT_H);
    land_lattice(rng, lat1, LAND_LAT2_W * LAND_LAT2_H);
    land_lattice(rng, rock, LAND_ROCK_W * LAND_ROCK_H);

    for (y = y0; y < y1; y++) {
        for (x = 0; x < WORLD_W; x++) {
            float fx = (float)x / (float)(WORLD_W - 1);
            float fy = (float)(y - y0) / (float)(span - 1);
            float ex = (fx - 0.5f) * 2.0f;
            float ey = (fy - 0.5f) * 2.0f;
            float d  = SDL_sqrtf(ex * ex + ey * ey);
            float n  = (0.62f * land_noise(lat0, LAND_LAT_W, LAND_LAT_H, fx, fy)
                      + 0.38f * land_noise(lat1, LAND_LAT2_W, LAND_LAT2_H, fx, fy))
                     - 0.5f;
            float h  = (1.0f - d) + n * rough;
            Uint8 s;

            /* Every sector gets its own water rim, so nothing can walk between sectors and
             * solid_at's out-of-bounds wall never has to be seen. */
            if (x == 0 || x == WORLD_W - 1 || y == y0 || y == y1 - 1)
                s = SURF_OCEAN;
            else if (h < sea)
                s = SURF_OCEAN;
            else if (land_noise(rock, LAND_ROCK_W, LAND_ROCK_H, fx, fy) > LAND_ROCK_T)
                s = SURF_ROCK;
            else
                s = SURF_LAND;

            w->surf[y][x] = s;
            w->solid[y][x] = (Uint8)(s != SURF_LAND);
            w->reveal[y][x] = 0.0f;
        }
    }
}

static void world_gen(World *w, Rng *rng)
{
    int x, y;

    gen_sector(w, rng, 0, OVERWORLD_H, LAND_SEA, LAND_ROUGH);

    /* The void band. Solid, so no traversal crosses it; SURF_OCEAN so it needs no new surface
     * kind — the dream sector recolours ocean to a violet starfield in Task 6, and this band is
     * drawn by the same path. */
    for (y = OVERWORLD_H; y < DREAM_Y0; y++)
        for (x = 0; x < WORLD_W; x++) {
            w->surf[y][x] = SURF_OCEAN;
            w->solid[y][x] = 1;
            w->reveal[y][x] = 0.0f;
        }

    /* A rougher coast for the dream sector, so it reads as clustered islets rather than a second
     * plain island. Deliberately NOT a higher sea threshold: fragmenting the sector into genuinely
     * separate islands would leave entities placed on islets the player cannot reach, and the
     * reachability
     * verifier would reject seeds forever. Ragged-but-connected gets the look without the fault. */
    gen_sector(w, rng, DREAM_Y0, WORLD_H, LAND_SEA, DREAM_ROUGH);
}
```

- [ ] **Step 1: Write the helper.**

```c
/* Graph adjacency for a tile: the four orthogonal neighbours, plus (from Task 4) the portal's
 * paired tile. `out` must hold 5.
 *
 * THIS IS THE WHOLE CORRECTNESS ARGUMENT FOR THE PORTAL. Five separate traversals answer
 * "what is next to this tile" — bfs_open for the region partition, flood_open for the spawn
 * component and --land-test, walk_regions for --gating-test's walk side, regions_build for the
 * adjacency bitmask, and autopilot_tick for pathing. If the portal edge were added to some but
 * not all of them, walk-reachable and graph-reachable would disagree and --gating-test would be
 * right to fail. One function means they cannot drift.
 *
 * Returns CANDIDATES, not passable tiles: each caller applies its own blocked test, because
 * flood_open reads `solid` while walk_regions reads tile_blocked with an ability mask. Mixing
 * those was never an option — see decision 33 on bridges. */
static int tile_neighbours(const World *w, int idx, int *out)
{
    static const int dx[4] = { 1, -1, 0, 0 };
    static const int dy[4] = { 0, 0, 1, -1 };
    int x = idx % WORLD_W, y = idx / WORLD_W, d, n = 0;

    (void)w;
    for (d = 0; d < 4; d++) {
        int nx = x + dx[d], ny = y + dy[d];
        if (nx < 0 || ny < 0 || nx >= WORLD_W || ny >= WORLD_H)
            continue;
        out[n++] = ny * WORLD_W + nx;
    }
    return n;
}
```

```c
/* The paired tile for a portal end, or -1 if `idx` is not one. Consulted by tile_neighbours (and
 * therefore by every traversal), by autopilot_tick and by the E interact in sim_step. */
static int portal_link(const World *w, int idx)
{
    if (w->portal[0] < 0 || w->portal[1] < 0)
        return -1;
    if (idx == w->portal[0]) return w->portal[1];
    if (idx == w->portal[1]) return w->portal[0];
    return -1;
}
```

- [ ] **Step 4: Write `place_portal`.** Runs in `game_init` **after** `world_gen`, `place_rivers`
and `place_buildings`, but **before** `regions_build` and the verifier — so the region partition

The overworld end goes on open ground; the dream end goes in the **largest** dream-sector open
component, which is the rule that keeps the dream landmass usable even when its ragged coast
leaves islets:

```c
/* Both ends on open ground, the dream end inside the LARGEST dream component. That last part is
 * the load-bearing rule: DREAM_ROUGH deliberately makes a ragged coast, so a portal dropped on a
 * two-tile islet would strand every fragment behind it and the verifier would reject seeds
 * forever. Placed before regions_build so the graph sees the portal edge like any other. */
static void place_portal(World *w, Rng *rng, Scratch *sc)
```

```c
/* Decision 36's shape, applied to the portal. There is no broken world to build here: flood_open
 * is exact and cannot "pass when it shouldn't". What is being verified is the CLAIM that the
 * portal is load-bearing - that it is the only way into the dream realm - so each seed is
 * generated twice and the test fails only if it never once observes the reachable component
 * shrink when the portal is suppressed.
 *
 * Written BEFORE the portal drew a single pixel. Phase 07 named a test to write first, it was
 * written second, and a screenshot loop spent a stretch suspecting a decoder bug the test
 * disproved in one run. */
static int portal_selftest(Uint64 seed, int nseeds)
{
    int fails = 0, s, shrank = 0, bearing = 0;

    for (s = 0; s < nseeds; s++) {
        int with = 0, without = 0, pass;
        for (pass = 0; pass < 2; pass++) {
            Game *g = (Game *)SDL_malloc(sizeof(Game));
            Scratch *sc = (Scratch *)SDL_malloc(sizeof(Scratch));
            Rngs rngs;
            int first, sx, sy, i, n;
            if (!g || !sc) { printf("FAIL  out of memory\n"); SDL_free(g); SDL_free(sc); return 1; }
            g_suppress_portal = pass;              /* pass 0 = normal, pass 1 = suppressed */
            rngs_init(&rngs, seed + (Uint64)s);
            game_init(g, &rngs);
            for (i = 0; i < WORLD_W * WORLD_H; i++) sc->seen[i] = 0;
            n = flood_open(&g->w, sc->seen, sc->stack,
                           (int)(g->p.x / TILE), (int)(g->p.y / TILE), &first, &sx, &sy);
            if (pass) without = n; else with = n;
            SDL_free(g); SDL_free(sc);
        }
        g_suppress_portal = 0;
        if (with > without) { shrank++; bearing++; }
        else if (with != without) {
            printf("FAIL  seed %d: suppressing the portal GREW the component, %d -> %d\n",
                   s, with, without);
            fails++;
        }
    }

    if (!shrank) {
        printf("FAIL  the portal never changed reachability on %d seeds - it is decoration\n",
               nseeds);
        fails++;
    } else {
        printf("negative control (portal is load-bearing): PASS  [%d/%d seeds shrank when "
               "suppressed]\n", shrank, nseeds);
    }
    printf("%s (%d checks failed)\n", fails ? "FAIL" : "PASS", fails);
    return fails ? 1 : 0;
}
```

```c
 * game_complete untouched. But the Well grants a REQUIRED Found Soul, so the shards feeding it are
 * mandatory - caught in design, not in code. The resolution is one more clause in world_solvable

static int shard_selftest(Uint64 seed, int nseeds)
{
    int fails = 0, s;
    for (s = 0; s < nseeds; s++) {
        Game *g = (Game *)SDL_malloc(sizeof(Game));
        Rngs rngs; int i, placed = 0, reachable = 0;
        rngs_init(&rngs, seed + (Uint64)s);
        game_init(g, &rngs);
        for (i = 0; i < SHARD_COUNT; i++) {
            if (g->shards[i] < 0) continue;

        }
        if (placed < SHARD_REQUIRED) {

        printf("negative control (shard-starved world rejected): %s\n", ok ? "FAIL" : "PASS");
        if (ok) fails++;
        SDL_free(g);
    }
    printf("%s (%d checks failed)\n", fails ? "FAIL" : "PASS", fails);
```
