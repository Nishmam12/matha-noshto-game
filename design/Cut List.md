# Cut List

Pre-committed, cut top-down if time runs short. See [[Agent Prompt]]'s working agreement — flag threats to the deadline early and propose the cut from here, don't quietly descope.

1. Second ability-gated ring of regions → ship a smaller landmass, same density of restoration beats. See [[World Generation]].
2. Reduce fragment/Found Soul counts further toward the low end of the default range (or below) if 20+ total proves too much for the timeline. See [[Fragments]], [[Found Souls]].
3. Third ability (Kindle) → ship with Wade + Climb only, redesign dark regions to not require it. See [[Abilities]].
4. Extra audio layers beyond a functional minimum (e.g. Base + Voice of Souls only, defer Strings/Pad/Bells). See [[Audio and Synth]].
5. Polish pass depth (screenshake, transition easing) → keep functional, cut refinement time.

**Never cut:** the fog-reveal core feel ([[Fog and Reveal]]), the reachability guarantee ([[World Generation]]), staying under the byte limit, having a defined completable end-state.
